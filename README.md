## ✨ Features

- **FortiGate CLI emulation** — typical `config system`, `config firewall policy`, `diagnose` commands
- **Policy + object editor** — firewall policies, address objects, service groups
- **FortiManager-style central management** view
- **FortiAnalyzer log viewer** simulation
- **Security Fabric** topology visualization
- **Browser-based** — no FortiOS license, no AWS / Azure FortiGate-VM bill

## 🚀 Quick Start

### Prerequisites
- Node.js 18+ OR Bun

### Local Development

```bash
npm install
npm run dev
```

The app runs on http://localhost:5173 (Vite default).

### Production Build

```bash
npm run build
npm run preview
```

## 🏗️ Stack

- **Vite** + **React** + **TypeScript**
- **Tailwind CSS** + **shadcn/ui**
- **Bun** for fast install / run
